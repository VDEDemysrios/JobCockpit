Job Cockpit

Trois questions, deux minutes. Tout se modifie ensuite dans profile/profile.json — rien n'est figé.

1. Qui signe les lettres ?

2. Qu'est-ce que tu cherches ?

Des intitulés courts, et peu nombreux. France Travail exige que tous les mots soient présents : « chargé de développement EnR » ne renvoyait rien là où « énergies renouvelables » renvoyait soixante offres. Deux ou trois suffisent pour commencer.

3. Où veux-tu travailler ?

Le code postal sert à déduire le département — c'est lui qui range les offres dans le bon onglet.

4. Tes clés d'accès — facultatif pour l'instant

Sans aucune clé, l'application démarre mais ne collecte rien. La plus utile est Gemini : c'est elle qui analyse les offres et rédige les lettres. Les autres s'ajoutent quand tu veux, dans .env.

Comment obtenir cette clé — 2 minutes, gratuit
  1. Ouvre aistudio.google.com/apikey et connecte-toi avec un compte Google — le tien suffit.
  2. Clique sur « Create API key ».
  3. Si on te demande un projet, prends celui qui est proposé ou clique « Create project » : son nom n'a aucune importance.
  4. Une longue suite de caractères apparaît, commençant par AIza. Copie-la et colle-la dans le champ ci-dessus.

C'est gratuit et sans carte bancaire, dans la limite d'un quota journalier. Quand il est atteint, l'application continue de collecter et de classer les offres — elle cesse simplement de les analyser jusqu'au lendemain.

La clé reste sur ton ordinateur, dans le fichier .env. Elle n'est envoyée qu'à Google, au moment d'analyser une offre ou d'écrire une lettre.

Les autres sources
Comment obtenir ces identifiants
  1. Ouvre developer.adzuna.com et clique sur « Sign up ».
  2. Renseigne ton e-mail. Adzuna t'envoie tes identifiants par courriel, sous une minute.
  3. Le message contient un Application ID (8 chiffres) et une Application Key (32 caractères) : recopie les deux ci-dessous.

Gratuit, sans carte bancaire. Adzuna agrège une large part des offres du marché privé.

Comment obtenir ces identifiants
  1. Crée un compte sur francetravail.io, puis une application.
  2. Le formulaire réclame une URL publique et refuse localhost. N'importe quelle page publique fait l'affaire — ton profil LinkedIn, par exemple.
  3. Souscris ensuite à l'API « Offres d'emploi v2 ». C'est une étape à part, que presque tout le monde oublie : sans elle, chaque collecte échoue en erreur 401.
  4. Recopie le client_id et le client_secret ci-dessous.

C'est la source la plus riche : la seule qui donne la description complète des offres.

Comment obtenir cette clé
  1. Ouvre fr.jooble.org/api/about et remplis le formulaire de demande.
  2. La clé arrive par courriel, en général sous 24 h.

Facultatif. Jooble est l'agrégateur dont la couverture ressemble le plus à Indeed.

Musique, directs et vidéos — l'onglet Chill

Rien à voir avec la recherche d'emploi : c'est de quoi souffler entre deux candidatures. Sans ces clés, l'onglet s'affiche quand même et t'indique quoi ajouter. Tu peux le faire plus tard, dans .env.

Comment obtenir ce Client ID
  1. Ouvre developer.spotify.com/dashboard et connecte-toi avec ton compte Spotify habituel.
  2. Clique « Create app ». Nom et description : ce que tu veux.
  3. Dans Redirect URI, colle exactement http://127.0.0.1:3000/spotify/retour, puis « Add ».
  4. Coche Web API, accepte les conditions, enregistre.
  5. Dans Settings, copie le Client ID ci-dessus.

Le Client Secret ne sert pas ici : la connexion passe par un flux qui n'en demande aucun. Ne le colle nulle part. Un compte Spotify Premium est nécessaire pour la lecture.

Comment obtenir ce Client ID
  1. Ouvre dev.twitch.tv/console/apps et connecte-toi. Twitch exige une double authentification sur ton compte.
  2. « Enregistrer votre application ». Nom : ce que tu veux.
  3. URL de redirection : http://localhost:3000. Catégorie : Application Integration.
  4. Type de client : Public.
  5. Valide, puis « Gérer » et copie le Client ID.

Sans cette clé, le lecteur Twitch fonctionne quand même : c'est la recherche de chaînes et de catégories qui en a besoin.

Comment obtenir cette clé
  1. Ouvre console.cloud.google.com et crée un projet — son nom n'a pas d'importance.
  2. Menu « API et services » → « Bibliothèque », cherche YouTube Data API v3, puis « Activer ».
  3. « Identifiants » → « Créer des identifiants » → « Clé API ».
  4. Copie la clé ci-dessus. Elle commence par AIza.

C'est une clé différente de celle de Gemini, même si les deux commencent pareil et viennent de Google. Sans elle, la lecture d'une vidéo marche ; c'est la recherche qui ne répond pas.
